## Descripción General
Portal web oficial del proyecto de grado BIBI, enfocado en el registro y visualización de datos de temperatura y humedad en las aulas de clase.

## Problema Identificado
Las altas temperaturas en los salones de la institución afectan la atención de los estudiantes. No se cuenta con mediciones exactas para gestionar mejoras en la infraestructura.

## Objetivo General
Desarrollar la plataforma digital BIBI integrada a sensores para monitorear el microclima escolar y presentar datos a la comunidad educativa.

## Tecnologías Utilizadas
* React.js
* Vite
* HTML5 y CSS3
* Git y GitHub

## Estado del Proyecto
